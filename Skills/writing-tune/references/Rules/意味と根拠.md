# 推敲で保つ意味

- 事実・対象・条件・因果関係に加え、書き手の判断理由、立場、説明の重点、主張の強さを保つ。同じ結論になる別の理由へ差し替えない。
- 短縮するときは、主体・対象・条件の範囲が曖昧にならないか確認する。読者が補う関係を増やしてまで短くしない。
- 観測から原因を断定したり、結果から設計の意図を推定したりしない。推測・仮定・確認済みの事実を区別する。
- 最新の原稿を基準にし、自然で明確な表現や意図のある語り口を残す。過去の版にあったことだけを理由に、削除済みの説明を戻さない。

# 語句と関係を明確にする

- 主語と述語、動詞と目的語、修飾語と対象の組み合わせを確認する。意味を推測できるだけでなく、その文脈で自然な表現を選ぶ。
- 指示語や省略した主体を特定できない場合は、必要な語を補う。文脈から明らかな省略まで一律に展開しない。
- 抽象的な動詞や名詞の組み合わせで説明を済ませず、実際の動作や関係を示す。意味のない分類名や独自の呼び方を増やさない。
- 専門語を平易にする際も、その語が区別する対象・条件・性質を保つ。言い換えると範囲が変わる場合は、用語を残して働きを短く添える。同じ概念の呼び方は文書内でそろえる。
- 「重要」「便利」「高度」などの評価は、何に対して、どの点でそう言えるかを伝える。区別に役立たない修飾語は省く。

# 主張と根拠を対応させる

- 結論や評価は、資料・観察・論理から言える範囲に合わせる。見出しや要約も、本文より広い主張にしない。
- 比較では対象・観点・条件をそろえ、違いが利用や判断にどう関わるかを示す。提案を強調するために比較対象の欠点を誇張しない。
- 参照資料の事実と、書き手の解釈・推測を区別する。未確認の情報は編集結果の報告で示し、確認できないことだけを理由に誤りと判断しない。
- 自然な語り口を演出するために、体験・感情・検証作業を作り足さない。内容の誤りを訂正する場合は、表現の推敲と区別して根拠を報告する。

# 条件と留保

- 注意書きを足す前に、主張自体の対象と範囲を正確にする。条件を主張に含めれば伝わる場合は、別の注意文を重ねない。
- 条件は該当する主張の近くに示す。削ると成立範囲を取り違える条件は残し、想定できる誤解や例外を網羅的に列挙しない。
- 否定や留保を削る際も、断定の強さや範囲を変えない。本文の過大な主張を、補足の注意書きだけで打ち消さない。

# 数値を扱う場合

- 資料の値、実測値、仮定、計算結果を区別し、解釈に必要な出典・単位・条件を示す。
- 元の値や仮定の精度を超える桁数を示さず、実測・試算・目安などの性質に合う表現を選ぶ。
- 結論や理解に使う数値を選ぶ。計算・測定の再現が目的なら手順も示し、それ以外の細部は必要に応じて補足へ分ける。
