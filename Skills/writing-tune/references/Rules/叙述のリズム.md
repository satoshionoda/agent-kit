# 叙述のリズム

文の長さ、段落の区切り、説明の順序、文末を整え、読み手が意味のまとまりを追いながら理解を進められる流れを作る。

- 個々の文だけでなく、段落や連続する箇条書きを通して読み、単調な反復や不自然な途切れを調整する。
- 変化を付けること自体を目的にせず、意味の明確さを優先する。並列の内容は表現をそろえる。

# 意味が明確に伝わる表現を選ぶ

- 短さより、意味が明確に伝わることを優先する。必要な説明を省いて、抽象的な一語にまとめない。
- 言葉の印象に頼らず、実際の対象・動作・関係を説明する。語が連想させる権威性や重要性などを、元の内容に加えない。

# 文の長さと区切り

- 1文で伝える要点を明確にし、条件や理由が重なって関係を追いにくい場合は分ける。原因と結果、条件と結論など、一緒に示すほうが分かりやすい関係は保つ。
- 文字数で機械的に区切らず、修飾先や条件のかかり先を読み直さずに理解できるかで判断する。読点を増やす前に、語順や修飾の長さを見直す。
- 条件によって扱いが変わる場合は、適用する場面を先に示す。`〜とする。ただし〜` を重ねず、条件ごとに整理する。

# 段落の役割とつながり

- ひとつの段落では、話題を中心に主張・理由・具体例をつなぐ。話題が変わる箇所で分け、問いや結論を独立させる場合は、その区切りが理解を助けるか確かめる。
- 省略・統合するときは、情報の重複だけでなく、前後をつなぐ役割も見る。紹介する理由や話題の転換まで削り、読み手に関係を補わせない。
- 要約は、長い説明の要点を整理する、複数の例を結び付ける、次の話題へつなぐ場合に使う。直前の説明を言い直すだけなら省く。
- 節末と次の節の冒頭を続けて読み、話題や説明の詳しさが変わっても関係を追えるか確認する。唐突な説明は、つなぎの文を足す前に配置や統合を検討する。
- 接続詞は実際の関係に合わせる。「そのため」は因果、「一方」は対比、「も」は共通点や追加の対象がある場合に使い、滑らかさのためだけに関係を作らない。

# 反復と変化

- 単調さを感じたら、語尾より先に、説明の重複や同じ展開の繰り返しを見直す。そのうえで、主語・構文・文の長さ・順序を調整する。
- 語尾を変えるためだけに、問いかけ、否定、推量を加えたり、時制や同じ概念の呼び方を変えたりしない。
- 比較や手順では、対応する項目の表現・観点・詳しさをそろえる。同じ文型が対応関係を助けているなら残す。
- 役割や重要度が異なる説明まで、同じ文数・分量・展開にそろえない。理解に必要な箇所を詳しくし、既に分かる内容は短くする。
- 見出しや一覧では、対象や役割を短く示す体言止めも使う。説明の流れが必要な箇所は、文や段落でつなぐ。

# 文末の意味と時制

- 定義・性質、状態・変化、実施報告、手順・助言を区別し、文の役割に合う述語を選ぶ。方法の有用性を説明する場合は、操作の予告だけでなく、その方法で分かることや得られる効果を示す。
- 実施した作業や判断は過去形、現在の性質・構成・規定は現在形で書く。予測や仮定を、確認済みの結果として書かない。
- 名詞で分類する文末は、その分類が説明の目的に合う場合に使う。動作を伝える文は動詞で述べ、状態と変化も書き分ける。

# 許可・可能・規定を書き分ける

- 文末は、その文が伝える意味に合わせる。
    - 許可: `〜してよい`
    - 能力や実現可能性: `〜できる`
    - 推奨: `〜を勧める` `〜が望ましい`
    - 規定や手順: `〜する` `〜とする`
- 文書全体が説明であっても、守るべき手順や条件は規定として言い切る。
    - NG `必要なときは、このガイドを参照してよい。`
    - OK `必要なときは、このガイドを参照する。`

## 英語の助動詞を直訳しない

英語の助動詞をそのまま訳すと、日本語では不要な婉曲表現や強すぎる言い方になり、不自然になることがある。

- 助動詞の訳語に引きずられず、文脈上の意味を自然な日本語で表す。
- 許可・可能・推奨・義務などの意味や強さを保つ。

# 回りくどい構文を避ける

- 文書や章の役割を説明するときは、`〜を扱う資料` のような分類で終えず、何を扱うかを直接述べる。
    - NG `この文書は、名前の付け方を扱う資料。`
    - OK `この文書では、名前の付け方を扱う。`
- 文書や章を主語にした直訳調を避け、`この文書では〜` `以下に〜を示す` など、自然な形にする。
    - NG `この章は、設定方法を説明する。`
    - OK `この章では、設定方法を説明する。`
- 言い換える際も、元の意味を保つ。たとえば、既存ルールを「説明する」ことと、新たに「定める」ことを混同しない。
