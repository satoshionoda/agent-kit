# 構造の選び方

情報同士の関係が分かるように、見出し・箇条書き・段落を使い分ける。

- 論点や段階が変わる箇所は、見出しで分ける。
- 並列に読ませたい項目は、箇条書きにする。一続きの説明は、段落で書く。
- 主項目に従属する補足・条件・例外・具体例は、短ければ同じ項目に書き、分ける必要がある場合に一段下げる。
- 項目数だけで分割せず、一覧として追いやすいか、異なる論点が混在していないかで判断する。数を減らすためだけの分類や階層は作らない。

# 各項目の書き方

- 主文は、その行だけで意味が通るように書く。
- 同じ階層には、役割と粒度がそろった項目を並べる。原則とその例外など、従属関係のある内容を並列にしない。
- 見出しや前後の文から分かる前置きや自明な動詞を繰り返さず、各項目に固有の内容を書く。
- 同じ主旨を言い換えて別項目にせず、ひとつにまとめる。

# 表との使い分け

- 表は、複数の対象を共通の観点で比較したり、対応関係を示したりする場合に使う。各項目に固有の特徴を紹介する場合は箇条書き、理由や話題のつながりを追う場合は段落を選ぶ。
- 表の列名が「説明」「特徴」のように広い場合は、行と列をそろえることで比較や参照がしやすくなるか確認する。件数や列数だけで決めず、文章の長さや狭い画面での読みやすさも考える。
- 箇条書きのラベルは、情報を探す・比較するために使う。後続の文を繰り返すだけなら省く。ラベルを外しても、拾い読みが必要な項目は箇条書きとして残す。
