# 基本方針

AIが使いがちな不自然な表現や、用途を限定したい語を扱う。

- 単語を機械的に置換せず、文脈と実際に指しているものに合わせて書き換える。
- 使用できる場面は、各項目に示す。
- 英語表現全般の判断は [英語表現の扱い](英語表現の扱い.md) を参照する。

# 避ける表現

## Source of Truth・正本

単に文書を指す場面に、不要な権威性や唯一性を持ち込まない。

- 通常は「文章」「ドキュメント」と書く。役割を示す必要がある場合は、「基準」「参照」「管理」「基本方針」など、意味に合う表現を選ぶ。
- `Source of Truth` はソフトウェア設計の文脈に限って使う。
- `正本` `副本` は法律の文脈に限って使う。

## 対話シェル

何を指すのか曖昧で、日本語としても不自然なため、通常の本文では使わない。

- 実際に指しているものに合わせて、`ターミナル` `シェル` `コマンドライン` `REPL` などを使う。
- 引用や、この語を避けるためのルール説明では使用できる。

# 追加方針

- 表現を追加するときは、避ける理由と自然な言い換えを併記する。
- 使用を禁止したいのか、多用を避けたいのかを区別する。
- 使用できる場面がある場合は、その範囲を明記する。
