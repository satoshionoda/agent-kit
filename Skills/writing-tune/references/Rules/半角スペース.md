# 半角スペース

- 日本語文中では、日本語と英数字・英語表現、数字と日本語の助数詞・単位の間に半角スペースを入れない。
- ただし、英語表現やインラインコードの内部に含まれる半角スペースは、その表記どおり保持する。
- インラインコードを文中で使う場合は、バッククォートの前後に半角スペースを入れる。

# 例

- NG `TypeScript について`
- OK `TypeScriptについて`
- NG `2 種類`
- OK `2種類`
- OK `npm scriptを実行する`
- OK `CSS Gridの仕様`
- OK `` `インラインコード` を使う ``
- OK `` `npm run dev` を実行する ``
