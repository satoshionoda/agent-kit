# 基本方針

日本語の文章中で、英語表現を残すか、訳すか、言い換えるかを判断する。

- 一般的な説明や操作案内では、自然な日本語や定着したカタカナ語を使う。
- 単語を機械的に置換せず、文脈に合わせて、役割や動作が伝わる表現を選ぶ。言い換えによって意味や指す対象を変えない。
- 助動詞や構文の直訳については [叙述のリズム](叙述のリズム.md)、使用を制限する語については [禁止ワード](禁止ワード.md) を参照する。

# 表記を保つもの

- パス、コマンド、コード、設定値、UI上の正式表記、固有名詞、引用は、元の表記を保つ。
- `AI` は原則としてそのまま使う。正式名称や定義が必要な場面では、その目的に合わせて補足する。

# 専門用語

- 読み手に共有されている専門用語は、無理に訳さず、意味を毎回説明しない。
- 何を指すか曖昧になる場合は、その文脈での意味を短く補足する。
- 読み手に馴染みがない用語は、意味を保てる自然な日本語に言い換えるか、必要な説明を添える。
