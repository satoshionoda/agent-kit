# このモードの役割

- 何を伝えたいか、何を含めるか、どう並べるかを整理する。
- 文章が意図と違うときの方向性の見直しや、箇条書き・断片的な材料の整理に使う。必要なら材料出しから始める。

# 進め方

- 目的・読者・前提と、伝えたい主張や迷っている点を整理する。
- 材料を集め、論点のまとまり、重複、不足を確認する。未確定の考えは、結論として扱わず残す。
- 目的・読者・利用場面を踏まえ、残す内容と外す内容、順番、情報の重心を検討する。
- 文章の構成案を箇条書きで示す。本文で伝える順に要点を並べ、各要点の下に、必要に応じて具体例や材料を置く。内容の選び方や並べ方に説明が必要な箇所だけ、構成の意図を短い文章で補う。必要に応じて [Rules/箇条書き](../Rules/箇条書き.md) を参照する。

# 作業の区切り

- 文体や細かな表現を磨かず、方向性と残る論点が分かる状態を目指す。
- 整理ができても自動で本文を書かない。人間が内容を確認し、文章化を依頼したら切り替える。
