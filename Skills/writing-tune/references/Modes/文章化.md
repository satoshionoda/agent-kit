# このモードの役割

- 新規作成・箇条書きからの清書・既存文章の推敲を扱い、用途に合った文章に整える。
- コンテクスト整理を先に通す必要はない。依頼、材料、既存文章から直接始める。

# 作成・編集

- 対象と前後の文脈を読み、[Rules](../index.md#rules) 配下の全ルールを毎回参照する。[文体と構成](../Rules/文体と構成.md) を踏まえ、目的・読者・利用場面に合わせて書き方を判断する。
- 意図を保ちながら材料を本文に展開し、必要な説明や接続を補う。事実や主張を勝手に作り足さない。
- 語や表記を機械的に置換せず、ルールの適用条件と文脈に照らして整える。
- 目的・読者・主張を左右する不明点は確認する。小さな説明の補足や構成の調整は、依頼の範囲で進める。

# 作業後の確認

- 対象全体を読み直し、意図とのずれ、情報の抜け、過剰な書き換えがないか確認する。
- 推敲では最新の原稿と照合し、[意味と根拠](../Rules/意味と根拠.md) に沿って理由・条件・主張の強さが保たれているか確認する。改善が明確でない言い換えは元の表現を残す。
- 書き終えた文章を、読み手が使う場面に沿って読み直す。必要な情報をすぐ見つけられるか、異なる役割の情報が一項目に混在していないかを確認し、見出し・段落・箇条書きの構成を調整する。
- 目的・読者・利用場面とRulesの全ルールに照らし、口調、文や段落の流れ、用語、表記を確認する。
    - 追加・修正した箇所は、前後の文や隣接する項目とのつながりも見る。
- 見出し・箇条書きなどの記法と、リンクや関連文書への影響を確認する。
- 削っても理解や判断が変わらない説明を省く。修正後は影響する前後も読み直し、具体的な問題が解消したら、言い換え自体を目的に推敲を続けない。
