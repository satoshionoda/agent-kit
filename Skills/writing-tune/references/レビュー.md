# 独立レビューの進め方

- 通常は、作業したエージェント自身が確認する。別の担当によるレビューは、明示的に依頼された場合だけ行う。
- レビュー担当には、対象、モード、目的・読者・利用場面、参照したガイド・ルールと、指定があれば文体や重点確認事項を渡す。条件が不明な場合は、未確定のまま伝える。
- レビュー担当は、対象全体と必要なガイドを自分で読み、次の観点で確認する。
    - 依頼・モード・目的・読者・利用場面に合っているか。
    - 情報の抜け、不自然な言い換え、過剰な書き換えがないか。
    - 文章化の場合は、Rulesの全ルールに照らして、口調や表現、表記に問題がないか。
    - Markdown記法やリンク構造が崩れていないか。
- 結果は、修正が必要な指摘と任意の提案を区別して返す。問題がなければ、その旨を伝える。
- 作業したエージェントが必要な修正を行い、指摘の解消を確認する。別の担当による再確認が必要な場合は、再レビューを依頼する。
- 依頼されたレビューが完了できなかった場合は、その状況と残る確認事項を人間に伝える。
