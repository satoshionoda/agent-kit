# agent-kit

satoshionodaが個人で使用している、AIとの会話・作業の方針、自作スキル、テンプレートを公開しているリポジトリ。内容は本人の用途や好みに合わせている。

## 読み方

文書とスキルの入口は [index](index.md)。AIには [AGENTS](AGENTS.md) を読み込ませ、そこから共通方針と必要なスキルを参照させる。Codex以外のAIでも、必要なMarkdownを直接読ませて使える。

## 出典とライセンス

外部のスキルをもとにした内容の作者・出典・ライセンスは [ATTRIBUTIONS](ATTRIBUTIONS.md) に記載している。
